# Runiq.Data Grouping Sample

## Demonstrates

- Grouping by one column
- Single grouped aggregation
- Multi aggregation
- Aggregation declaration order
- Nullable grouped aggregation input

## Run

```powershell
dotnet run --project samples/Runiq.Data.Samples.Grouping
```

## Key APIs

- `DataFrame.GroupBy`
- `GroupedDataFrame.Sum`
- `GroupedDataFrame.Aggregate`
- `GroupAggregationBuilder.For`
