# Runiq.Data Aggregations Sample

## Demonstrates

- Global numeric aggregations
- Min and max aggregations
- Row counts
- Nullable aggregation input

## Run

```powershell
dotnet run --project samples/Runiq.Data.Samples.Aggregations
```

## Key APIs

- `DataFrame.Sum`
- `DataFrame.Average`
- `DataFrame.Min`
- `DataFrame.Max`
- `DataFrame.Rows.Count`
