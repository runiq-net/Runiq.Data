# Runiq.Data Joining Sample

## Demonstrates

- Inner joins
- Left joins
- Right joins
- Full joins
- Different key column names
- Composite keys

## Run

```powershell
dotnet run --project samples/Runiq.Data.Samples.Joining
```

## Key APIs

- `DataFrame.InnerJoin`
- `DataFrame.LeftJoin`
- `DataFrame.RightJoin`
- `DataFrame.FullJoin`
- `DataFrameJoin.On`
