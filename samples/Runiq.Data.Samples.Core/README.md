# Runiq.Data Core Sample

## Demonstrates

- Creating a DataFrame from object columns
- Inspecting schema and counts
- Reading cells
- Copying a DataFrame
- Taking leading rows

## Run

```powershell
dotnet run --project samples/Runiq.Data.Samples.Core
```

## Key APIs

- `DataFrame.Create`
- `DataFrame.Schema`
- `DataFrame.Copy`
- `DataFrame.Head`
- `DataFrame.Take`
