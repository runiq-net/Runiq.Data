# Runiq.Data Filtering and Sorting Sample

## Demonstrates

- Filtering rows with dynamic cell comparisons
- Sorting rows ascending
- Sorting rows descending
- Removing duplicate rows and duplicate keys

## Run

```powershell
dotnet run --project samples/Runiq.Data.Samples.FilteringAndSorting
```

## Key APIs

- `DataFrame.Filter`
- `DataFrame.Rows.SortBy`
- `DataFrame.Rows.SortByDescending`
- `DataFrame.Distinct`
